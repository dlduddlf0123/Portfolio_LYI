## 파일 목록 및 설명
- AddressableManager.cs: 어드레서블 관리, 에셋 데이터 관리
- BiDirectionalDictionary.cs: 커스텀 자료구조 구현
- Constants.cs: 전역 상수 및 설정값 관리
- GameManager.cs: 게임 전체 흐름 및 상태 관리
- ObjectPoolingManager.cs: 오브젝트 풀링을 통한 성능 최적화
- Tok_Character.cs: 캐릭터 애니메이션 관리 클래스
- Tok_Movement.cs: 캐릭터 데이터 및 이동 관리 클래스
- Trap\_Shooting.cs: 게임 내 상호작용 오브젝트 구현
- UI_Table.cs: 주요 상호작용 UI 관리 및 동작 구현
